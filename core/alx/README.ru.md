## Что такое ALX

ALX — реализованный в этой папке транспорт: авторизация, формат передачи
потоков, пересылка UDP, управление соединениями и выбор сетевого пути.
В Preview 8 оставлен один режим — **Turbo**.

~~~text
Android TUN -> hev-socks5-tunnel -> локальный SOCKS5 ALX
  -> Turbo: QUIC/TLS 1.3 или TLS 1.3/TCP с Chrome-подобным ClientHello
  -> сервер ALX -> Интернет
~~~

ALX не изобретает собственный шифр. За шифрование и обмен ключами отвечают
стандартные реализации TLS 1.3 и QUIC. Собственная часть ALX начинается выше:
авторизация, транспорт, пересылка UDP и выбор пути.

## Возможности Turbo

| Область | Как работает Preview 8 |
|---|---|
| Выбор пути | Проверяются QUIC и TCP, используется первый успешно авторизованный |
| TCP | Chrome-подобный ClientHello и HTTP/1.1 Upgrade |
| Авторизация | HMAC-SHA256 с привязкой к текущей TLS-сессии |
| Защита от повтора | Время, случайный nonce и серверный кэш |
| Проверка сервера | Сертификат TLS и SHA-256 SPKI-отпечаток |
| UDP | QUIC datagrams и надёжный поток для крупных пакетов |
| Смена ключей | До двух временно действующих старых токенов |
| Неверные запросы | Обычный веб-ответ и ограничение частоты |
| Скорость | Адаптивные буферы, повторное использование соединений и BBR для QUIC |

В Turbo нет искусственного padding, мусорного трафика, случайных задержек и
обязательного CDN.

## Сборка и тестирование

~~~bash
go mod download
go mod verify
go test -race ./...
go build -trimpath -ldflags='-s -w' -o alx-server ./cmd/alx-server
go build -trimpath -ldflags='-s -w' -o alx-check ./cmd/alx-check
~~~

Проверка реальной загрузки через локальный ALX SOCKS:

~~~bash
./alx-check -config client.json \
  -url 'https://speed.cloudflare.com/__down?bytes=10485760' -attempts 3
~~~

Тестер показывает выбранный транспорт, успешные попытки, время до первого
байта, объём, скорость и последнюю ошибку. Для честного сравнения разные
протоколы нужно проверять на одном телефоне, сервере, маршруте и в одно время.

## Настройка и эксплуатация

Для установки на VPS вместе с Remnawave используйте
[автоустановщик sidecar-ноды](deploy/remnawave/README.md). Официальная Node и
ALX работают отдельно, поэтому обновления Remnawave/Xray не перезаписывают
наш транспорт.

Готовые шаблоны находятся в папке [deploy](deploy). Токен должен содержать
минимум 32 случайных байта в Base64URL. Не храните боевые токены в репозитории.

При смене ключа новый токен помещается в ALX_TOKEN, а текущий временно — в
ALX_PREVIOUS_TOKENS. После обновления клиентов старый токен нужно удалить.
Одновременно принимается не более двух старых токенов.

## Статус безопасности

Код содержит модульные и интеграционные тесты маршрутизации TLS, привязки
авторизации к сессии, ограничения неверных запросов и смены токенов. Независимый
аудит пока не проводился. Перед публикацией сервера прочитайте
[SECURITY.md](../../SECURITY.md).
